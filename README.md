# Machine-Learning-Lab
## Linear Regression - USA Housing Price Prediction

In this lab, we applied Linear Regression to predict housing prices in different regions of the USA using housing-related features such as area income, house age, number of rooms, number of bedrooms, and population.

We began by loading and exploring the dataset using Pandas, followed by data visualization with Seaborn and Matplotlib through pairplots, histograms, and heatmaps to understand relationships between variables. After preparing the feature and target variables, we split the dataset into training and testing sets.

A Linear Regression model was trained using Scikit-learn and evaluated by analyzing model coefficients, predictions, and residual errors. We also used regression evaluation metrics including MAE, MSE, and RMSE to measure model performance. This project demonstrated how Linear Regression can be used for predicting continuous numerical values in real-world datasets.
