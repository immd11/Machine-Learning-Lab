# Machine-Learning-Lab
## Logistic Regression Project - Advertisement Click Prediction

In this lab, we used Logistic Regression to predict whether a user would click on an online advertisement based on demographic and internet usage data. The dataset included features such as age, daily internet usage, daily time spent on site, area income, and gender.

We began by exploring and visualizing the dataset using Seaborn and Matplotlib through histograms, jointplots, and pairplots to better understand relationships between features and user behavior. After preprocessing the data, we split it into training and testing sets.

A Logistic Regression model was then trained using Scikit-learn and evaluated using a confusion matrix and classification report. The project demonstrated how Logistic Regression can be used for binary classification problems and how user behavior data can help predict advertisement engagement.
