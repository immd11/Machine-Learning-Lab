# Machine-Learning-Lab
## Random Forest & Decision Tree - Loan Prediction Project

In this lab, we explored machine learning classification using Decision Trees and Random Forests on LendingClub loan data. The goal was to predict whether a borrower would fully repay their loan or not based on financial and credit-related features.

The project included data exploration and visualization using Seaborn and Matplotlib, such as FICO score distributions, loan purposes, and interest rate trends. We also handled categorical data using dummy variables before splitting the dataset into training and testing sets.

Two models were trained and evaluated: a Decision Tree Classifier and a Random Forest Classifier. Their performance was compared using confusion matrices and classification reports. The Random Forest achieved higher overall accuracy, while the Decision Tree performed slightly better in detecting unpaid loans, showing the impact of class imbalance in machine learning classification problems.
