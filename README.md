#  House Pricing – Data Preprocessing  

##  Overview
This project focuses on assessing data quality and applying preprocessing techniques to a real-world House Pricing dataset before building machine learning models.  
The dataset includes numerical and categorical features such as property price, area, number of bathrooms, furnishing type, ownership, and more.


##  Tools Used
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Scikit-learn  

---

##  Conclusion
Proper preprocessing improves data quality, reduces noise, and prepares the dataset for building accurate and reliable machine learning models.
