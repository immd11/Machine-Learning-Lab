# ARTI308 – Machine Learning Lab 5

## Overview

This lab focuses on applying data preprocessing and feature engineering techniques on a real-world house pricing dataset. The goal is to prepare the data for machine learning models and understand how different features can affect house prices.

## Dataset

The dataset contains information about residential properties such as price, location, area, furnishing status, number of bathrooms, balconies, and other property details.


## Goal

The objective of this lab is to understand how proper data preprocessing and feature engineering improve the performance of machine learning models when predicting house prices.
