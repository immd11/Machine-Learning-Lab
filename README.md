# Machine-Learning-Lab
## Support Vector Machines (SVM) - Iris Dataset

In this chapter, we explored the Support Vector Machine (SVM) algorithm using the famous Iris dataset. The project included loading and visualizing the dataset with Seaborn, creating pairplots and KDE plots to understand the relationships between flower features, and identifying separable classes.

We then split the dataset into training and testing sets and trained an SVM classifier using Scikit-learn. After evaluating the model with a confusion matrix and classification report, the model achieved very high accuracy. Finally, we applied GridSearchCV to tune hyperparameters such as `C` and `gamma` in order to improve model performance and practice model optimization techniques.
